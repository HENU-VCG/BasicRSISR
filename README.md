# BasicRSISR

A Toolbox for Remote Sensing Image Super-Resolution

## Overview

BasicRSISR is a planned toolbox for remote sensing image super-resolution.
The project aims to bring model information, dataset references, documentation,
and reproducible evaluation procedures into one place.

**Current status:** This repository currently contains the project introduction only.
Implementation code, installation instructions, pretrained weights, dataset entries,
and benchmark results are still to be added.
